# Laboratorio Piloto de Nave

Realidad Mixta - Grupo 2 - Universidad de San Buenaventura 2026-2

Simulador de nave en Unity controlado con Arduino, comparando tres protocolos de comunicación serial: CSV, JSON y binario.

## Carpetas

- **Arduino:** sketches de los tres protocolos.
- **Unity:** proyecto de Unity con la nave.
- **Mediciones:** datos crudos de las pruebas.
- **Evidencia:** videos y capturas.

## Cómo usarlo

1. Abrir la carpeta `Unity` con Unity 6 y la escena `Assets/Scenes/SampleScene`.
2. Subir al Arduino el sketch del protocolo que se quiere usar y cerrar el monitor serial.
3. En la nave, dejar solo el receptor de ese protocolo, poner el puerto COM correcto y dar Play.
